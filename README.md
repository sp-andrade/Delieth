# Delieth 🍰
 
Delieth es una aplicación web para pedir postres (cheesecakes, pasteles y cupcakes). Este repositorio contiene la maquetación de las pantallas iniciales del flujo de acceso: **Landing**, **Inicio de sesión** y **Crear cuenta**, construidas con **HTML + Tailwind CSS**.
 
## Pantallas incluidas
 
### 1. Landing
Página de bienvenida / presentación de la marca, punto de entrada antes de iniciar sesión o registrarse.
 
### 2. Inicio de sesión
Formulario para que un usuario existente acceda con sus credenciales (correo/usuario y contraseña).
 
### 3. Crear cuenta
Formulario de registro para nuevos usuarios (nombre, correo, contraseña, etc.).
 
## Tecnologías
 
- HTML5
- [Tailwind CSS](https://tailwindcss.com/) (vía CDN — `cdn.tailwindcss.com`)
